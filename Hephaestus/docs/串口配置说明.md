# 串口配置说明

## 一，当前策略

当前版本先使用你已有的串口配置

是否做固定串口绑定由你后续自行决定，本版本不修改 udev 规则，不强制创建 `/dev/atlas_*` 设备名

## 二，当前 ASRPRO 参数

```yaml
asrpro_port: "/dev/ttyUSB0"
asrpro_baud: 115200
```

运行时可通过 launch 参数覆盖：

```bash
ros2 launch robot_startup robot_start.launch.py asrpro_port:=/dev/ttyUSB1
```

## 三，查看当前串口

```bash
ls /dev/ttyUSB* /dev/ttyACM*
dmesg -w
```

## 四，后续如需绑定

后续可根据设备的 `idVendor`，`idProduct`，`serial` 自行编写 udev 规则

本版本只提供说明，不自动更改系统串口绑定
