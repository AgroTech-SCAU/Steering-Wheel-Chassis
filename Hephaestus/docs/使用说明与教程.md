# Atlas PI 端使用说明与教程

## 一，编译

```bash
cd ~/chassis-pi-ws
colcon build --symlink-install
source install/setup.bash
```

## 二，一键启动

```bash
cd ~/chassis-pi-ws
source install/setup.bash
ros2 launch robot_startup robot_start.launch.py
```

终端只保留关键状态日志，完整任务日志保存在：

```text
chassis-pi-ws/log/日期时间-log.txt
```

## 三，比赛流程

1. 先完成遥操作任务
2. MCU 通过已有 AutoPi 手势切换到自动模式
3. PI 收到 AutoPi START 事件
4. ASRPRO 播报“遥操作区任务已完成”
5. ASRPRO 播报“请说阿特拉斯启动”
6. 队员说“阿特拉斯启动”
7. ASRPRO 上报 `atlas_start`
8. PI 启动全自主运输任务

## 四，单独测试导航

```bash
ros2 service call /navigate_to_target send_navigation_target/srv/NavigateToTarget "{waypoint_id: 'P1'}"
```

## 五，单独测试视觉

```bash
ros2 service call /vision_detect vison_topic_interfaces/srv/VisionDetect "{start: true}"
sleep 2
ros2 service call /vision_detect vison_topic_interfaces/srv/VisionDetect "{start: false}"
```

## 六，单独测试 ASRPRO

启动整车后查看日志：

```bash
tail -f log/*-log.txt
```

正常应看到 ASRPRO 串口打开，握手，等待 `atlas_start`
