# Atlas 智械争锋全自主区状态机说明

## 1. 任务范围

状态机从机器人位于中转区、MCU 已锁存全自主任务开始，执行以下闭环：

```text
中转区安全停止
→ 播报“遥操作区任务已完成”
→ 接收语音启动文本（可配置）
→ 导航至智能分拣区
→ 识别齿轮与 T 型螺栓对应的园区
→ 导航至待派送区
→ 识别并抓取一个货物
→ 导航至对应园区
→ 投放货物
→ 返回待派送区继续派送
→ 达到数量、无目标终止条件或时间边界
→ 安全收臂、制动并向 MCU 上报结果
```

状态机进入运行阶段后不提供返回遥操作区的转移。MCU 进入手动、故障、急停、清除自动任务锁存或状态超时时，导航和机械臂任务会被取消，底盘速度被置零，并请求制动。

## 2. 状态层级

生命周期状态位于 `AutonomousTransportStatus.state`：

```text
BOOTSTRAP
WAIT_MCU_STATUS
WAIT_START
PRECHECK
RUNNING
REPORTING_DONE / REPORTING_FAIL
WAIT_RESET / RECOVERY_REQUIRED
SHUTTING_DOWN
```

运输阶段位于 `AutonomousTransportStatus.stage`：

```text
ANNOUNCE_TRANSITION
WAIT_VOICE_START
NAVIGATE_SORTING_AREA
CLASSIFY_SORTING_RULE
NAVIGATE_DISPATCH_AREA
SELECT_CARGO
PICK_CARGO
NAVIGATE_TARGET_PARK
PLACE_CARGO
COMPLETE / FAILED
```

## 3. 关键安全门控

- 地图坐标、停车朝向、机械臂动作和视觉参数未确认时，`calibration_confirmed: false` 会阻止状态机进入运动阶段。
- 四个地图停车点必须具有非空且互不重复的编号，`x_m/y_m` 停车位置不得重合。
- 完整导航后端使用 `absolute_map`，任务点按 `map` 坐标解释。
- 导航速度只在运行中的已受理导航操作期间转发至 `/motor_cmd_vel`。
- 平面线速度受到状态机二次限幅，最大值不会超过赛事要求的 `2.0 m/s`。
- 导航、识别、抓取、投放、等待、结果上报阶段均保持明确的速度权限。
- 每次导航前执行 `transport_arm_safe`，确保机械臂位于底盘安全包络。
- 投放失败时保持安全停止，不继续携货移动。
- `/mcu/set_brake`、导航服务、机械臂服务、分类服务和结果上报服务全部就绪后才允许启动。
- MCU RESET 会清除本轮任务计数、园区映射、异步操作和待处理启动事件。

## 4. 分类与派送策略

智能分拣服务对 RACOM 识别结果进行多次采样，并根据画面左右位置建立：

```text
park_1 -> gear 或 t_bolt
park_2 -> 另一类别
```

`classification.minimum_confidence` 控制园区映射的最低置信度。默认值为 `0.60`，要求两个分类标识形成完整映射；低置信度结果会进入识别重试。

待派送区货物计划为齿轮与 T 型螺栓交替选择，每类目标数量为 4。视觉任务每次最多处理一个货物。连续达到无目标阈值的类别不再进入本轮选择，状态机继续检查另一类别。

## 5. 配置文件

### 场地与策略

```text
chassis-pi-ws/src/app/atlas_autonomous_transport_manager/config/autonomous_transport.yaml
```

需要填写：

- 智能分拣区、待派送区、园区 1、园区 2 的 `map` 坐标与 yaw；
- 全自主区实际可用时间预算；
- 语音启动策略；
- 分类置信度阈值；
- 导航、分类、抓取重试次数。

### 机械臂动作

```text
chassis-pi-ws/src/vision_system/atlas_vision_pollination_backend/config/transport_actions.yaml
```

需要标定：

- 导航安全收臂位姿；
- 分类标识观察位姿；
- 待派送区识别与抓取位姿；
- 两个园区各四个投放槽位；
- 预抓取、抓取工具点偏移；
- 动作速度、到位超时和吸盘建立时间。

### 分类规则

```text
chassis-pi-ws/src/vision_system/racom_vision/atlas_racom_vision_backend/config/sorting_rule.yaml
```

需要确认：

- 图像左槽、右槽与园区编号的对应关系；
- 图像中心和中心死区；
- 模型类别名称与 `gear`、`t_bolt` 的别名映射。

### 像素到相机坐标

```text
chassis-pi-ws/src/vision_system/racom_vision/atlas_racom_vision_backend/config/racom_camera_target.yaml
```

需要标定：

- 固定工作距离或目标深度；
- 图像中心；
- 像素到米的横向、纵向比例；
- 相机坐标方向与机械臂手眼外参。

## 6. 启动与观察

构建：

```bash
cd ~/Atlas/chassis-pi-ws
source /opt/ros/humble/setup.bash
colcon build --symlink-install
source install/setup.bash
```

整车启动：

```bash
ros2 launch robot_startup robot_autonomous_transport.launch.py
```

状态观察：

```bash
ros2 topic echo /atlas/autonomous_transport/status
ros2 topic echo /atlas/navigation/status
ros2 topic echo /atlas/manipulation/status
ros2 topic echo /mcu/status
```

语音识别节点应把最终文本发布至：

```text
/atlas/voice/command
```

识别文本命中配置中的 `accepted_phrases` 后，状态机进入智能分拣区导航阶段。

## 7. 实车启用条件

完成以下检查后，将 `autonomous_transport.yaml` 中的门控设为：

```yaml
calibration_confirmed: true
```

启用前应确认：

1. 四个地图点位均已实测且机器人完整位于可行驶区域；
2. 机械臂各动作无碰撞、无超限，收臂后不超出底盘安全包络；
3. 吸盘抓取后可在导航振动下保持货物；
4. 投放后货物完整落入对应园区；
5. 分类标识左右映射在实际停车朝向下正确；
6. 急停、刹车、MCU 状态超时和手动接管均能触发零速度；
7. 全自主区时间参数符合现场裁判的实际计时口径。
