# Atlas 全自主运输状态机详细说明及错误处理

## 1 双层状态结构

状态机由生命周期和任务阶段组成

生命周期

```text
BOOTSTRAP
WAIT_MCU_STATUS
WAIT_START
PRECHECK
RUNNING
REPORTING_DONE
REPORTING_FAIL
WAIT_RESET
RECOVERY_REQUIRED
SHUTTING_DOWN
```

任务阶段

```text
IDLE
ANNOUNCE_TRANSITION
ANNOUNCE_VOICE_PROMPT
WAIT_VOICE_START
ANNOUNCE_AUTONOMOUS_START
NAVIGATE_SORTING_AREA
CLASSIFY_SORTING_RULE
NAVIGATE_DISPATCH_AREA
SELECT_CARGO
PICK_CARGO
NAVIGATE_TARGET_PARK
PLACE_CARGO
COMPLETE
FAILED
```

生命周期决定系统是否允许任务运行；任务阶段决定全自主运输当前执行哪一步

## 2 启动事件可靠性

状态机同时使用两种信息

```text
/mcu/auto_task_event 的 EVENT_START
/mcu/status 的 app_state=AutoPi + auto_start_latched=true
```

边沿事件用于及时启动；锁存状态用于补偿节点启动较晚；ROS 重启或瞬时丢失单次事件

默认参数

```text
accept_latched_start_without_event=true
```

因此只要 MCU 的 AutoPi 锁存仍有效；状态机就能进入 PRECHECK；不会因为 launch 延时而丢失手势

## 3 PRECHECK

PRECHECK 不直接启动运动；逐项检查

```text
MCU 状态新鲜
MCU 处于 AutoPi
任务锁存有效
Pi 在线标志有效
底盘 ready
里程计 ready
机械臂 ready
统一 YAML 校验通过
ASRPRO 串口连接且设备 ready
导航启动和取消服务可用
机械臂启动和取消服务可用
智能分拣服务可用
MCU 制动服务可用
任务结果上报服务可用
ASRPRO 播报服务可用
```

设备或服务暂时未就绪时；保持安全停止并继续等待；不会立即进入不可恢复错误

配置错误属于确定性错误；例如占位地图点或动作数量不足；进入 `RECOVERY_REQUIRED` 并要求修复配置

## 4 阶段超时和跳过原则

用户要求的主原则

```text
普通阶段错误；重试后跳过
安全权限变化；立即打断
```

普通阶段错误包括

```text
ASRPRO 播报超时
导航目标超时
智能分拣识别超时
单次视觉抓取超时
单类无目标
机械臂普通动作失败
```

这些错误不会让状态机无限停留在当前阶段

安全权限变化包括

```text
Manual 接管
EStop
MCU Fault
MCU 离开 AutoPi
任务锁存被清除
MCU 状态超时
```

这些条件立即取消后端；制动并结束当前任务上下文

## 5 各阶段错误处理

### 5.1 中转区播报失败

```text
重试 speech_retry_count 次
→ 记录跳过阶段
→ 继续语音提示或下一安全阶段
```

播报失败不允许底盘运动；语音触发仍根据 ASRPRO 实际状态执行

### 5.2 等待语音启动

默认

```yaml
start_timeout_s: 0.0
fallback_enabled: false
```

表示持续等待；此阶段不是死锁；因为 Manual 接管；RESET；EStop 和 MCU 状态监控始终有效

如现场明确允许超时自动启动；可设置

```yaml
start_timeout_s: 15.0
fallback_enabled: true
```

比赛推荐保持关闭；避免没有有效语音识别时误启动

### 5.3 前往智能分拣区失败

```text
导航重试
→ 记录 NAVIGATE_SORTING_AREA 跳过
→ 若明确启用后备园区映射则继续
→ 否则后续无法获得园区映射并安全结束派送
```

默认不猜测裁判摆放结果

### 5.4 分类识别失败

```text
classification_retry_count 次重试
→ 可选 YAML 后备映射
→ 未启用后备映射时跳过派送并部分完成收尾
```

### 5.5 前往待派送区失败

```text
导航重试
→ 跳过剩余取货和派送
→ COMPLETE
```

### 5.6 抓取无目标

视觉后端明确返回 `target_found=false` 或 `target_count=0`

```text
当前类别 no_target_counts + 1
→ 跳过本次抓取
→ 选择下一类别
```

同一类别达到 `no_target_limit_per_class` 后不再选择；另一类别仍可继续

### 5.7 抓取动作失败

```text
pick_retry_count 次重试
→ 记录跳过
→ continue_on_pick_failure=true 时继续选择其他货物
```

### 5.8 持货导航失败

机器人可能仍吸住货物；因此处理为

```text
取消导航
持续制动
保持吸盘状态
不继续移动
进入 COMPLETE 部分收尾
```

禁止为了继续得分而在未知位置释放货物

### 5.9 投放失败

```text
记录 PLACE_CARGO 跳过
保持吸盘状态
停止后续移动
进入 COMPLETE
```

### 5.10 时间预算到达

安全收尾窗口

```text
未持货且 remaining <= stop_reserve_s
→ 不再发起新抓取
→ COMPLETE
```

硬时间上限

```text
remaining <= 0
→ 立即取消后端
→ 持续零速度和制动
→ 不再启动播报或机械臂动作
→ 按已完成数量上报
```

## 6 Manual 接管

检测到 `McuStatus.STATE_MANUAL` 后

```text
取消导航
取消机械臂任务
清空当前异步操作
持续发送零速度
请求 MCU 制动
进入 WAIT_RESET
```

Manual 接管优先级高于任何普通阶段错误

## 7 RESET 和恢复手势

状态机接收

```text
AutoTaskEvent.EVENT_RESET
或 auto_start_latched 1 -> 0
```

收到后立即清理本轮上下文；如果 MCU 已处于安全空闲状态；直接返回 WAIT_START；否则进入 WAIT_RESET

恢复动作不会依赖视觉；导航；ASRPRO 或机械臂服务；因此普通后端故障不会阻止恢复手势生效

## 9 错误码

```text
4102 MCU 状态超时
4103 MCU 急停
4104 MCU 故障
4105 Manual 接管
4106 MCU 离开 AutoPi 或清除锁存
4201 到 4209 预检条件未满足
4401 到 4404 内部操作类型冲突
4501 MCU 未确认任务结果
4502 结果上报服务超时
4503 结果上报服务异常
4504 结果上报被拒绝
```

普通阶段跳过不一定设置致命错误码；使用 `skipped_stage_count` 和 `last_skipped_stage` 追踪

## 10 排查顺序

```text
先检查 /mcu/status
→ 再检查 /atlas/asrpro/status
→ 再检查 /atlas/autonomous_transport/status
→ 再检查导航和机械臂状态
→ 最后检查视觉服务和模型日志
```

不要在没有确认 MCU 模式和任务阶段时直接测试底盘速度
