# Atlas 串口和相机固定绑定教程

## 1 目标名称

```text
/dev/atlas_mcu
/dev/atlas_asrpro
/dev/atlas_lidar
/dev/atlas_camera
```

固定名称用于避免 USB 插拔顺序改变后 `/dev/ttyUSB0`；`/dev/ttyUSB1` 或 `/dev/video0` 互换

## 2 查询设备属性

逐个拔插设备；确认当前设备节点

```bash
ls -l /dev/ttyUSB* /dev/ttyACM* /dev/video* 2>/dev/null
```

查询串口

```bash
udevadm info -a -n /dev/ttyUSB0 | less
udevadm info -q property -n /dev/ttyUSB0
```

重点记录

```text
ID_VENDOR_ID
ID_MODEL_ID
ID_SERIAL_SHORT
ID_PATH
```

查询相机

```bash
udevadm info -q property -n /dev/video0
v4l2-ctl --list-devices
```

## 3 推荐规则

创建规则

```bash
sudo nano /etc/udev/rules.d/99-atlas-devices.rules
```

使用真实值替换示例中的 VID；PID 和序列号

```udev
# MCU 串口
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="55d4", ATTRS{serial}=="MCU_SERIAL", SYMLINK+="atlas_mcu", MODE="0666", GROUP="dialout"

# ASRPRO TWEN51 串口
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", ATTRS{serial}=="ASRPRO_SERIAL", SYMLINK+="atlas_asrpro", MODE="0666", GROUP="dialout"

# 串口雷达
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="55d3", ATTRS{serial}=="LIDAR_SERIAL", SYMLINK+="atlas_lidar", MODE="0666", GROUP="dialout"

# USB 相机主视频节点
SUBSYSTEM=="video4linux", ENV{ID_VENDOR_ID}=="2bdf", ENV{ID_MODEL_ID}=="0001", ENV{ID_V4L_CAPABILITIES}==":capture:", SYMLINK+="atlas_camera", MODE="0666", GROUP="video"
```

同型号设备没有唯一序列号时；使用物理 USB 端口路径

```udev
SUBSYSTEM=="tty", KERNELS=="1-1.2", SYMLINK+="atlas_mcu", MODE="0666", GROUP="dialout"
SUBSYSTEM=="tty", KERNELS=="1-1.3", SYMLINK+="atlas_asrpro", MODE="0666", GROUP="dialout"
```

`KERNELS` 值从以下命令中查找

```bash
udevadm info -a -n /dev/ttyUSB0 | grep KERNELS
```

物理端口规则要求比赛时设备插在固定 USB 口

## 4 生效规则

```bash
sudo udevadm control --reload-rules
sudo udevadm trigger
sudo usermod -aG dialout,video "$USER"
```

注销并重新登录；或重启

```bash
sudo reboot
```

## 5 验证

```bash
ls -l /dev/atlas_mcu
ls -l /dev/atlas_asrpro
ls -l /dev/atlas_lidar
ls -l /dev/atlas_camera
```

串口读取权限

```bash
test -r /dev/atlas_mcu && test -w /dev/atlas_mcu && echo MCU_OK
test -r /dev/atlas_asrpro && test -w /dev/atlas_asrpro && echo ASRPRO_OK
```

相机测试

```bash
v4l2-ctl -d /dev/atlas_camera --all
```

## 6 工程配置对应关系

```text
mcu_comm_bridge.yaml        port: /dev/atlas_mcu
asrpro.yaml                 port: /dev/atlas_asrpro
lslidar_n10p_uart.yaml      serial_port: /dev/atlas_lidar
autonomous_transport.yaml  system.vision.camera: /dev/atlas_camera
```

## 7 常见问题

### 7.1 两个串口 VID 和 PID 完全相同

优先使用 `ATTRS{serial}`；没有序列号时使用 `ID_PATH` 或 `KERNELS`

### 7.2 相机生成多个 video 节点

使用 `ENV{ID_V4L_CAPABILITIES}==":capture:"` 过滤；再通过 `v4l2-ctl --list-devices` 确认主采集节点

### 7.3 systemd 启动时找不到设备

确认规则在重启后立即生成符号链接；服务设置了自动重启；设备晚到时对应节点会重试连接

### 7.4 ModemManager 抢占串口

若 ASRPRO 或 MCU 被 ModemManager 打开；可添加

```udev
ENV{ID_MM_DEVICE_IGNORE}="1"
```

或在确认系统不需要后禁用 ModemManager

```bash
sudo systemctl disable --now ModemManager
```
