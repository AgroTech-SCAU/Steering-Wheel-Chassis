# Atlas Pi 工作区详细介绍及完整任务流

## 1 工作区边界

本工作区只负责 Pi 端全自主运输；PC 端保持不变；MCU 固件保持不变；遥操作区逻辑保持现有实现

核心目录

```text
chassis-pi-ws/
├── src/
│   ├── app/
│   │   ├── atlas_mission_interfaces/
│   │   └── atlas_autonomous_transport_manager/
```


## 2 功能包职责

### 2.1 atlas_mission_interfaces

统一定义导航；机械臂；智能分拣；ASRPRO 和全自主状态消息及服务

ASRPRO 接口

```text
AsrproStatus.msg
AsrproEvent.msg
AsrproSpeak.srv
```

### 2.2 atlas_autonomous_transport_manager

职责

```text
等待 MCU AutoPi
执行安全预检
编排中转区播报和语音启动
调用智能分拣识别
调用导航和机械臂后端
门控导航速度
处理重试；跳过；时间预算和结果上报
响应 Manual；RESET；Fault 和 EStop
```

状态机不直接打开串口；不直接运行模型；不直接求机械臂逆解；只通过稳定 ROS 接口协调各后端

### 2.3 atlas_asrpro_bridge

职责

```text
打开 /dev/atlas_asrpro
维护 HELLO 握手和心跳
把 phrase_id 播报请求转换为串口帧
把 ASR intent 转换为 /atlas/asrpro/recognized
处理 ACK；NACK；重试；去重和重连
```

### 2.4 mcu_comm_bridge

职责

```text
接收 MCU_STATUS；IMU；Odom 和机械臂状态
发布 AutoTaskEvent
接收状态机门控后的 /motor_cmd_vel
提供制动；吸盘；机械臂目标和任务结果服务
```

MCU 仍然拥有模式切换和 AutoPi 启动权；Pi 不能主动切换模式

### 2.5 at_nav2

启动 Cartographer 纯定位；静态地图服务和 Nav2；把 Nav2 的 `/cmd_vel` 重映射到 `/atlas/navigation/cmd_vel`

### 2.6 atlas_nav_full_backend

把状态机的 `StartNavigation` 服务转换为 Nav2 `NavigateToPose`；全自主区使用 `absolute_map`

### 2.7 vison_topic

来自最新 `vision_system.zip`；负责打开相机；加载 ONNX 模型；输出类别和像素中心

模型路径可由统一 YAML 的 `system.paths.vision_model_path` 配置；留空使用内置 `resource/best.onnx`

### 2.8 atlas_racom_vision_backend

包含两个适配节点

```text
racom_camera_target_service
sorting_rule_service
```

前者把像素目标转换为机械臂后端使用的相机坐标目标；后者识别齿轮和 T 型螺栓对应的园区

### 2.9 atlas_vision_pollination_backend

复用现有机械臂动作执行框架；读取 `transport_actions.yaml`；执行安全收臂；视觉抓取；吸盘控制和园区投放

## 3 话题和服务主链路

### 3.1 启动链路

```text
遥控器 AutoPi 手势
→ MCU app_state=AutoPi
→ MCU auto_start_latched=1
→ /mcu/status + /mcu/auto_task_event
→ atlas_autonomous_transport_manager
```

状态机既接收 START 边沿事件；也检查持续锁存状态；因此状态机晚于 MCU 启动时仍能补偿单次事件

### 3.2 ASRPRO 链路

```text
状态机 /atlas/asrpro/speak
→ atlas_asrpro_bridge
→ USB ASCII 协议 SPEAK
→ ASRPRO 本地播报
→ EVENT SPEAK_DONE
→ /atlas/asrpro/event
```

```text
用户说 Atlas 启动
→ ASRPRO 离线识别
→ EVENT ASR atlas_start
→ atlas_asrpro_bridge
→ /atlas/asrpro/recognized
→ 状态机语音门控通过
```

### 3.3 导航速度链路

```text
Nav2 /cmd_vel
→ remap /atlas/navigation/cmd_vel
→ 全自主状态机速度权限检查和二次限幅
→ /motor_cmd_vel
→ mcu_comm_bridge
→ PI_CONTROL
→ MCU
```

只有当前操作为已受理导航；生命周期为 RUNNING；没有安全停止时才转发非零速度

### 3.4 视觉抓取链路

```text
状态机 StartManipulation
→ atlas_vision_pollination_backend
→ /vision/detect_camera_target
→ atlas_racom_vision_backend
→ /vision_detect
→ vison_topic 最新 ONNX 模型
→ 像素目标
→ 相机目标
→ 手眼变换和工具点运动
→ MCU 机械臂与吸盘服务
```

## 4 严格任务流

### 4.1 进入全自主区

遥操作区由现有系统完成；机器人进入中转区后；使用已有 AutoPi 手势切换 MCU 模式

状态机确认

```text
MCU 状态新鲜
app_state=AutoPi
auto_start_latched=true
Pi 在线
底盘 ready
里程计 ready
机械臂 ready
ASRPRO ready
所有依赖服务 ready
配置校验通过
```

### 4.2 中转区语音流程

```text
ANNOUNCE_TRANSITION
→ 播报 transition_complete
→ ANNOUNCE_VOICE_PROMPT
→ 播报 voice_prompt
→ WAIT_VOICE_START
→ 收到 atlas_start
→ ANNOUNCE_AUTONOMOUS_START
→ 播报 autonomous_start
```

底盘在整个语音阶段持续制动

### 4.3 智能分拣

```text
NAVIGATE_SORTING_AREA
→ 导航前安全收臂
→ 到达智能分拣观察点
→ sorting_scan_prepare
→ CLASSIFY_SORTING_RULE
→ 多样本识别左右标识
→ 建立 park_1 和 park_2 的货物类别映射
```

### 4.4 待派送区取货

```text
NAVIGATE_DISPATCH_AREA
→ 安全收臂
→ 到达待派送区
→ SELECT_CARGO
→ 按 gear；t_bolt 交替计划选取类别
→ PICK_CARGO
→ dispatch_pick_prepare
→ 识别单件目标
→ 工具点接近
→ 打开吸盘
→ 收臂并保持吸盘
```

### 4.5 园区派送

```text
NAVIGATE_TARGET_PARK
→ 持货安全收臂
→ 导航到类别对应园区
→ PLACE_CARGO
→ 执行当前园区下一个槽位动作
→ 关闭吸盘
→ 更新派送计数
→ 返回待派送区
```

每个园区最多配置四个投放槽位；货物允许堆叠时也必须保证接触面平行并完整进入园区

### 4.6 结束条件

```text
完成 8 件
两类目标都达到无目标阈值
智能分拣无法获得有效映射
剩余时间进入安全收尾窗口
硬时间上限到达
关键投放或持货导航无法继续安全执行
```

正常收尾

```text
底盘制动
→ 播报 task_complete
→ 尝试安全收臂
→ 取消后端残留任务
→ 向 MCU 上报 DONE
→ WAIT_RESET
```

## 5 恢复流

```text
恢复手势
→ MCU auto_start_latched 1 -> 0
→ MCU 发布 RESET 或 Pi 检测锁存下降沿
→ 状态机取消后端
→ 清除本轮任务数据
→ WAIT_START
```

清除内容包括

```text
语音识别标志
播报事件
分类映射
派送计数
当前货物和园区
持货标志
重试计数
跳过计数
异步 future
已失效 START 事件
```

## 6 不允许的跨层行为

```text
Pi 主动切换 MCU 到 AutoPi
Nav2 直接发布到底盘最终速度话题
视觉节点直接控制底盘
ASRPRO 直接控制 MCU
状态机绕过机械臂后端直接写串口
进入全自主后重新回到遥操作任务
```
