# Atlas 全自主运输区配置指南

## 1 适用范围

本指南只配置智械争锋全自主运输区；遥操作区；PC 端和 MCU 固件不在本次配置范围内

完整任务由以下入口统一启动

```bash
ros2 launch robot_startup robot_autonomous_transport.launch.py
```

统一配置文件位于

```text
chassis-pi-ws/src/app/atlas_autonomous_transport_manager/config/autonomous_transport.yaml
```

该 YAML 同时管理启动顺序；导航后端；视觉模型路径；相机设备；ASRPRO；任务时间；园区映射策略；地图点和机械臂动作名称

## 5 统一 YAML 的 system 段

### 5.1 启动延时

```yaml
system:
  startup:
    asrpro_delay_s: 0.0
    mcu_delay_s: 0.0
    sensor_delay_s: 1.0
    navigation_delay_s: 2.0
    vision_delay_s: 3.0
    manipulation_delay_s: 4.0
    manager_delay_s: 6.0
```

启动延时只负责组织节点顺序；状态机仍会检查 MCU 状态；ASRPRO 状态和所有依赖服务；因此不要通过缩短延时绕过预检

### 5.2 路径解析规则

`system.paths` 中留空表示使用功能包安装目录中的默认文件；填写绝对路径时直接使用；填写相对路径时按统一 YAML 所在目录解析

示例

```yaml
system:
  paths:
    vision_model_path: "/home/wheeltec/models/best.onnx"
    vision_labels_path: "/home/wheeltec/models/labels.txt"
    map_yaml: "/home/wheeltec/maps/competition.yaml"
    cartographer_pbstream: "/home/wheeltec/maps/competition.pbstream"
```

路径包含空格时必须使用引号

## 6 最新视觉模型配置

最新 `vision_system.zip` 已放入

```text
chassis-pi-ws/src/vision_system
```

默认模型位于

```text
src/vision_system/rui_vison/vison_topic/resource/best.onnx
```

编译后安装到

```text
install/vison_topic/share/vison_topic/resource/best.onnx
```

统一 YAML 中的配置

```yaml
system:
  paths:
    vision_runtime_config: ""
    vision_model_path: ""
    vision_labels_path: ""
  vision:
    camera: "/dev/atlas_camera"
    confidence_threshold: 0.55
    process_every_n: 2
    rate_hz: 10.0
```

`vision_model_path` 留空时使用内置最新模型；填写后使用外部模型；若填写路径不存在；视觉节点会明确报错并退出；launch 会按配置重启节点

模型参数优先级从高到低为

```text
统一 YAML 中 system.paths 和 system.vision
→ vision_runtime.yaml
→ detect_and_send.py 默认值
```

类别文件每行一个名称；当前比赛适配器至少需要识别齿轮和 T 型螺栓对应类别；默认别名位于

```text
src/vision_system/racom_vision/atlas_racom_vision_backend/config/sorting_rule.yaml
```

视觉配置和标定见 `docs/视觉模型配置与标定.md`

## 7 ASRPRO TWEN51 配置

ASRPRO 固件应包含以下稳定 intent

```text
atlas_start
```

建议离线识别词

```text
Atlas 启动
阿特拉斯启动
开始全自主运输
```

ASRPRO 固件应包含以下 phrase_id

```text
transition_complete
voice_prompt
autonomous_start
delivery_complete
task_complete
task_skipped
```

统一 YAML 配置

```yaml
autonomous_transport:
  voice:
    start_required: true
    start_timeout_s: 0.0
    fallback_enabled: false
    asrpro_status_timeout_s: 2.0
    speech_timeout_s: 8.0
    speech_retry_count: 2
    accepted_intents: ["atlas_start"]
```

`start_timeout_s: 0.0` 表示一直等待语音触发；等待期间底盘制动；机械臂不动作；恢复手势和遥控接管仍保持有效

ASRPRO 详细适配见 `docs/ASRPRO_TWEN51适配与烧录说明.md`

## 8 导航配置

全自主区四个停车点必须使用 `map` 绝对坐标

```yaml
autonomous_transport:
  waypoints:
    sorting_area:
      x_m: 0.0
      y_m: 0.0
      yaw_rad: 0.0
    dispatch_area:
      x_m: 0.0
      y_m: 0.0
      yaw_rad: 0.0
    park_1:
      x_m: 0.0
      y_m: 0.0
      yaw_rad: 0.0
    park_2:
      x_m: 0.0
      y_m: 0.0
      yaw_rad: 0.0
```

标定方法

1. 启动定位和 Nav2；不要启动任务状态机
2. 手动把机器人停到智能分拣识别位；记录 `map -> base_footprint`
3. 记录待派送区抓取位；园区 1 投放位；园区 2 投放位
4. 每个停车点至少重复到达五次；检查机械臂可达性和底盘边界余量
5. 将平均值写入 YAML；保留足够的障碍物和围栏余量

读取位姿

```bash
ros2 run tf2_ros tf2_echo map base_footprint
```

完整导航后端必须保持

```yaml
coordinate_mode: "absolute_map"
```

对应文件

```text
src/app/atlas_autonomous_transport_manager/config/autonomous_full_nav.yaml
```

## 9 智能分拣标识配置

配置文件

```text
src/vision_system/racom_vision/atlas_racom_vision_backend/config/sorting_rule.yaml
```

必须确认

```yaml
left_slot_park: "park_1"
right_slot_park: "park_2"
image_center_u_px: 320.0
center_deadband_px: 20.0
allow_complement_inference: false
```

裁判会改变齿轮和 T 型螺栓对应园区；因此默认设置

```yaml
use_fallback_mapping_on_failure: false
```

识别失败时状态机记录该阶段并安全结束派送；不会猜测错误园区

## 10 机械臂动作配置

动作文件

```text
src/vision_system/atlas_vision_pollination_backend/config/transport_actions.yaml
```

必须逐项标定

```text
transport_arm_safe
sorting_scan_prepare
dispatch_pick_prepare
park_1_drop_prepare
park_2_drop_prepare
place_park_1_slot_1 到 place_park_1_slot_4
place_park_2_slot_1 到 place_park_2_slot_4
pick_one_gear
pick_one_t_bolt
```

标定顺序

1. 断开底盘动力或架空轮组；验证急停
2. 只测试 `transport_arm_safe`
3. 测试智能分拣观察位姿；确认相机可同时看到两个标识槽位
4. 测试待派送观察位姿和单件抓取
5. 测试持货状态下的安全收臂
6. 分别测试两个园区的四个投放槽位
7. 验证投放后货物完全进入得分区；吸盘能够稳定关闭

动作数据仍为场地占位值时；不得打开 `calibration_confirmed`

## 11 恢复和跳过策略

推荐配置

```yaml
autonomous_transport:
  recovery:
    navigation_retry_count: 1
    classification_retry_count: 2
    pick_retry_count: 1
    continue_on_pick_failure: true
```

普通导航；识别；抓取或播报超时会先重试；超过上限后记录并进入安全后继阶段；不会永久停留在当前阶段

以下条件属于安全中断；不会按普通阶段错误跳过

```text
遥控器切回 Manual
MCU 急停
MCU Fault
MCU 离开 AutoPi
MCU 状态超时
MCU RESET
```

## 12 最终启用门控

全部标定完成后再修改

```yaml
autonomous_transport:
  calibration_confirmed: true
```

状态机还会检查

```text
四个导航点 ID 非空且互不重复
四个 x/y 停车位置不重合
地图点不是全零占位
动作名称完整
每个园区至少有四个投放任务
ASRPRO 就绪
MCU 处于 AutoPi 且锁存有效
导航；机械臂；分类；制动和结果上报服务就绪
```
