## 6 鲁棒性确认

状态机对普通阶段异常采用以下处理

- 播报失败；按配置重试后跳过播报
- 智能分拣区导航失败；重试后结束无映射任务
- 分类识别失败；重试后仅在明确启用后备映射时继续；默认安全结束
- 待派送区导航失败；重试后进入安全收尾
- 单件抓取失败或无目标；记录类别次数并继续选择其他货物
- 园区导航失败；保持吸盘状态并进入安全收尾
- 投放失败；保持吸盘状态并进入安全收尾
- 任务时间上限到达；取消后端；持续零速度；按已完成数量上报
- MCU 恢复事件或锁存下降沿；清理全部本轮状态并返回等待启动
- 遥控器人工接管；立即取消导航和机械臂；持续零速度与制动；等待恢复手势
- MCU 急停；故障或状态超时；立即进入全局安全停止

## 7 当前运行限制

本验证环境未安装 ROS 2 Humble 和 `colcon`；因此没有执行完整工作区构建；ROS 图运行；真实 Nav2 导航；真实机械臂动作；真实 ASRPRO 串口和实车联调

当前工程保留以下安全门控

```yaml
autonomous_transport:
  calibration_confirmed: false
```

以下数据必须在实车上完成后才能改为 `true`

- 智能分拣区；待派送区；园区 1；园区 2 的 `map` 坐标与朝向
- 导航定位地图；Cartographer `pbstream` 和 Nav2 参数
- 相机固定设备名；分辨率；置信度和类别映射
- 分类标识左右槽位与园区对应关系
- 相机内参；手眼外参；默认深度或深度来源
- 安全收臂；识别位姿；抓取位姿；四个园区投放槽位动作
- ASRPRO 六个 phrase_id；`atlas_start` intent；ACK；事件重发和播报期间识别门控
- `/dev/atlas_mcu`；`/dev/atlas_asrpro`；`/dev/atlas_lidar`；`/dev/atlas_camera` 固定绑定

在 `calibration_confirmed=false` 时；状态机只完成通信；状态监测与配置预检；不会发起导航或机械臂运动
