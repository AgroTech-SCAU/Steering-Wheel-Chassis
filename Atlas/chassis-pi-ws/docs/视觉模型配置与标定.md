
## 3 视觉运行参数

```yaml
system:
  vision:
    camera: "/dev/atlas_camera"
    confidence_threshold: 0.55
    process_every_n: 2
    rate_hz: 10.0
    service_name: "vision_detect"
    topic_name: "vision_detections"
```

树莓派负载高时优先增大 `process_every_n`；不要先大幅降低相机帧率；智能分拣采用短窗口多样本；需要保证每个窗口至少产生数次有效推理

## 6 智能分拣标定

配置文件

```text
src/vision_system/racom_vision/atlas_racom_vision_backend/config/sorting_rule.yaml
```

在 `sorting_scan_prepare` 位姿下采集图像；确认

```text
两个标识都完整可见
左右标识不会被机械臂遮挡
左右槽位在画面中的顺序稳定
图像中心值与实际输入宽度一致
类别名称能映射到 gear 和 t_bolt
```

调用测试

```bash
ros2 service call /vision/classify_sorting_rule \
  atlas_mission_interfaces/srv/ClassifySortingRule \
  "{request_id: sorting_calibration}"
```

至少分别测试两种裁判摆放

```text
左齿轮；右 T 型螺栓
左 T 型螺栓；右齿轮
```

返回的 `park_1_cargo` 和 `park_2_cargo` 必须随摆放正确变化

正式配置保持

```yaml
allow_complement_inference: false
```

每次分类必须同时确认齿轮和 T 型螺栓；只识别到一类时本次分类判定失败并进入重试

## 7 待派送区目标标定

配置文件

```text
src/vision_system/racom_vision/atlas_racom_vision_backend/config/racom_camera_target.yaml
```

当前模型输出二维像素；适配器通过固定深度和像素比例形成相机坐标近似值

需要标定

```yaml
default_depth_m: 0.30
image_center_u_px: 320.0
image_center_v_px: 320.0
pixel_to_meter_x: 0.00050
pixel_to_meter_y: 0.00050
```

标定方法

1. 固定底盘和 `dispatch_pick_prepare` 位姿
2. 在待派送区放置单个标定目标
3. 记录目标像素中心和机械臂实际需要到达的相机坐标
4. 在图像中心；左右；上下至少各采集三组
5. 拟合像素到米比例和中心偏移
6. 在待派送区边缘位置验证误差

如果相机有可靠深度；应后续替换固定深度近似；当前接口不应把未经验证的二维映射当作精确三维测量

## 10 与状态机的关系

视觉节点启动失败时；状态机 PRECHECK 会因分类或机械臂依赖服务未就绪而保持安全等待

运行中识别失败时；对应阶段按 YAML 重试；达到上限后跳过；不会无限等待

模型路径错误不会自动回退到其他模型；这样能够避免现场误用错误权重
