# atlas_mission_yasmin — 智械争锋全自主区

状态机只负责比赛任务编排，不保存导航坐标、视觉像素占比或底层 `wz` 参数

主流程：

`WAIT_AUTO -> ARM_ZERO -> NAV_ORIGIN -> INSPECT_SORT_ZONE -> ARM_NAV_SAFE_INITIAL -> NAV_PICKUP -> OBSERVE_PICKUP -> PICK -> ...`

规则：智能分拣区在车前进方向左侧判为 B 区，右侧判为 A 区；同一次识别返回 gear/t_bolt 的园区映射；导航后端根据 `arena=A/B` 选择对应半图

上下文记录 4 个固定货物点位的真实剩余层数和独立轮次调度状态；1/2 轮对应点位 0，3/4 轮对应点位 1，5/6 轮对应点位 2，7/8 轮对应点位 3。正常流程下奇数轮（1/3/5/7）运输高层、偶数轮（2/4/6/8）运输低层，但实际 `expected_layer` 始终以该点位当前剩余货物为准：例如第 1 轮高层识别失败后，第 2 轮仍然识别/运输高层；若第 2 轮高层成功，则继续停留在第 2 轮阶段运输同点位低层。只有抓取成功才减少真实剩余层数，视觉失败只推进/延期调度，不会错误地把高层当成已经运输。1~4 轮结束后会先补偿点位 0/1 的失败项，再进入 5~8 轮，以避免未清空货物干涉后续机械臂运动。视觉内部用 `expected_layer` 校验目标，只向 YASMIN 返回 `layer_ok/complete`。

识别恢复顺序：固定预识别位 -> 机械臂换视角 -> 底盘小角度 yaw 扫描；底盘扫描完成后必须回标准朝向
