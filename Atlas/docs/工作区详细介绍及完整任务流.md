# 工作区详细介绍及完整任务流

## 一，工作区结构

| 路径 | 作用 |
|---|---|
| `chassis-pi-ws/src/mcu_comm_bridge` | MCU 与 PI 通信桥 |
| `chassis-pi-ws/src/nav_system/robot_startup` | PI 端整车启动入口 |
| `chassis-pi-ws/src/nav_system/at_nav2` | Cartographer 定位与 Nav2 |
| `chassis-pi-ws/src/nav_system/send_navigation_target` | 航点 ID 到 Nav2 目标的服务桥 |
| `chassis-pi-ws/src/vision_system/rui_vison` | 当前使用的视觉检测系统 |
| `chassis-pi-ws/src/app/atlas_autonomous_task` | 智械争锋全自主运输状态机 |

## 二，已停用的重复包

以下包保留源码，但通过 `COLCON_IGNORE` 停用，避免和 `rui_vison/` 中同名包冲突：

```text
vision_system/raicom_vsion/vison_topic
vision_system/raicom_vsion/vison_topic_interfaces
vision_system/racom_vision/atlas_racom_vision_backend
```

## 三，完整任务流

```text
MCU AutoPi START
  -> ASRPRO 播报遥操作完成
  -> ASRPRO 等待 atlas_start
  -> 导航到中转区 / 智能分拣区
  -> rui_vison 识别分类标识
  -> 导航到待派送区
  -> 根据识别结果导航到园区 1 或园区 2
  -> 播报派送完成
  -> 上报 DONE 给 MCU
```

## 四，导航链路

```text
atlas_autonomous_task
  -> /navigate_to_target
  -> send_navigation_target
  -> Nav2 NavigateToPose
  -> /motor_cmd_vel
  -> mcu_comm_bridge
  -> MCU
```

## 五，视觉链路

```text
atlas_autonomous_task
  -> /vision_detect start=true
  -> rui_vison 持续检测
  -> /vision_detect start=false
  -> 返回 cls_names / u_px / v_px
```
