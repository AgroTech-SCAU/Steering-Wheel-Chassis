# 状态机详细说明及错误处理

## 一，状态机阶段

| 阶段 | 动作 | 失败处理 |
|---|---|---|
| `WAIT_AUTOPI` | 等 MCU AutoPi START | 一直等待 |
| `SPEAK_TELEOP_DONE` | 播报遥操作完成 | 超时则记录并继续 |
| `WAIT_ASR_START` | 等 `atlas_start` | 默认一直等待 |
| `SPEAK_AUTO_START` | 播报开始全自主 | 超时则记录并继续 |
| `NAV_TO_SORT` | 导航到中转区 / 智能分拣区 | 失败则跳过 |
| `RUI_VISION_DETECT` | 识别分类标识 | 失败使用 fallback |
| `NAV_TO_PICKUP` | 导航到待派送区 | 失败则跳过 |
| `NAV_TO_ZONE` | 导航到园区 | 失败则跳过 |
| `FINISH` | 播报并上报 DONE | 上报失败只记录 |

## 二，恢复手势

MCU 发出 RESET 事件后，PI 立即设置中断标志

当前任务线程会在下一次阶段检查时退出，并关闭 ASRPRO 监听

## 三，遥控器接管

任务运行中，如果 MCU 不再处于 `AutoPi`，或 `auto_start_latched` 被清除，PI 立即中断任务

PI 不主动请求 MCU 切换模式，不修改遥控手势

## 四，阶段失败策略

默认：

```yaml
skip_failed_stage: true
```

含义是导航，视觉，播报等单阶段失败只记录并跳过，避免全自主任务彻底卡死

严重异常才会上报 FAIL
