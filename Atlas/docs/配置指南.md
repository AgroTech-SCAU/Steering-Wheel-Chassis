# Atlas PI 端配置指南

## 一，启动入口

PI 端统一使用：

```bash
cd ~/chassis-pi-ws
source install/setup.bash
ros2 launch robot_startup robot_start.launch.py
```

`robot_startup` 会启动 MCU 通信桥，雷达，机器人模型，完整导航，`send_navigation_target`，`rui_vison/` 视觉服务和全自主任务状态机

## 二，导航配置

完整导航直接使用已有 `robot_startup` 和 `at_nav2`

状态机不改导航内部，只调用：

```text
Service: /navigate_to_target
Type:    send_navigation_target/srv/NavigateToTarget
Request: waypoint_id: "P1" ~ "P15"
```

Nav2 速度输出在 `robot_startup` 中配置为 `/motor_cmd_vel`，由 MCU 在 `AutoPi` 状态下消费

## 三，视觉配置

视觉使用现有拼写目录：

```text
chassis-pi-ws/src/vision_system/rui_vison/
```

ROS 包名保持原样：

```text
vison_topic
vison_topic_interfaces
```

检测服务：

```text
Service: /vision_detect
Type:    vison_topic_interfaces/srv/VisionDetect
```

类别默认映射：

| 类别名 | 任务含义 | 默认园区 |
|---|---|---|
| `chilun` | 齿轮 | 园区 1 |
| `luosi` | 螺丝 / T 型螺栓 | 园区 2 |

## 四，ASRPRO 配置

ASRPRO TWEN51 通过 USB 串口连接树莓派

当前先使用已有串口配置，不强制绑定串口：

```yaml
asrpro_port: "/dev/ttyUSB0"
asrpro_baud: 115200
```

需要改串口时通过 launch 参数传入：

```bash
ros2 launch robot_startup robot_start.launch.py asrpro_port:=/dev/ttyUSB1
```

## 五，任务配置

主配置文件：

```text
chassis-pi-ws/src/app/atlas_autonomous_task/config/autonomous_task.yaml
```

常用字段：

| 字段 | 说明 |
|---|---|
| `waypoint_sort` | 中转区 / 智能分拣区航点 |
| `waypoint_pickup` | 待派送区航点 |
| `waypoint_zone_1` | 园区 1 航点 |
| `waypoint_zone_2` | 园区 2 航点 |
| `vision_scan_duration_s` | 视觉检测窗口 |
| `skip_failed_stage` | 阶段失败是否跳过 |
